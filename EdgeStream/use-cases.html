Use Cases

EdgeStream is the communication backbone for any system that requires real-time, context-aware, auditable message delivery. From enterprise SaaS to financial trading platforms, EdgeStream ships the infrastructure so your team focuses on business logic.

Core communication patterns

Every EdgeStream deployment follows one or more of these four fundamental patterns. Each is supported out of the box with no custom routing code.

Real-Time Collaboration
Multiple users edit the same document, whiteboard, or form simultaneously. EdgeStream's topic-based isolation ensures User A's changes are delivered to User B without leaking to unrelated sessions.
Collaborative editing Whiteboarding Simultaneous form editing Live cursor sharing
Workflow Integration
Form submissions trigger workflow execution in ProcessEngine. ExecutionNodes receive messages via subscription. Real-time step progress flows back to the UI — with full context preserved through every state transition.
Multi-step approvals Human-in-the-loop Batch processing SLA tracking
Multi-Client Broadcasting
Backend events fan out to all subscribed clients. Wildcard topics (order:*:status) deliver to all interested subscribers simultaneously. Context-aware filtering ensures each client receives only relevant messages.
Live dashboards System notifications Real-time metrics Alert broadcasting
Cross-Platform Sync
Web browser, React Native mobile app, and Electron desktop all subscribe to the same topics. A change in one client propagates instantly to all others — same IEnvelope, same hook pipeline, same delivery guarantees.
Multi-device sync Universal state Offline-capable Background reconnect

AI Agent integration

EdgeStream's MCP Server adapter makes it a native communication layer for AI agents and LLM toolchains. Agents subscribe to topics, publish messages, and participate in workflows — just like any other service.

Multi-Agent Handoffs
AI agents subscribe to topics and publish responses. When a customer service agent escalates to a specialist, the conversation context travels intact through the EdgeStream pipeline — no manual context passing between agent instances.
Agent handoffs Context preservation MCP integration
LLM Streaming Responses
Token-by-token LLM output published to a topic. The UI subscribes and updates character-by-character. No custom streaming infrastructure — EdgeStream delivers each token through the same pipeline as any other message.
Streaming responses Token delivery Real-time typing
Agentic Workflow Coordination
Multiple AI agents and human approvers participate in a shared workflow. ProcessEngine tasks, human-in-the-loop approvals, and agent completions all surface as EdgeStream messages with full context for every participant.
Multi-agent workflows Human approval loops ANCP integration
