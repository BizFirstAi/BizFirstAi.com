# BizFirstAi.com

BizFirstAi root marketing site — documentation and website source.

Site content is served from the [`/docs`](./docs) folder via GitHub Pages.

DataOcean, InstallHub, MarketHub, Octopus, OperateAI, Passport) live in their own
dedicated repos under the `BizFirstAi` org.

[`/Archived`](./Archived) holds the previous, obsolete copy of this repo's content,
kept for reference only — not served.
